# Security

miniZeep should remain an observer-side, local presentation mod.

Please report vulnerabilities involving arbitrary code execution, unsafe file
handling, credential exposure, or unintended multiplayer authority through a
private GitHub security advisory when possible. Do not post secrets, lobby
codes, private chat, or personal data in a public issue.

Normal gameplay bugs and compatibility problems can be reported through the
public issue tracker with reproduction steps and a redacted log excerpt.
